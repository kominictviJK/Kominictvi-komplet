# Kominictví Komplet

Pracovní aplikace pro iPad – Kominictví Klimesch (Jan Klimesch, Šternberk).

Webová aplikace (PWA) bez sestavování: HTML, CSS a JavaScript. Data se ukládají jen v iPadu (IndexedDB), aplikace funguje offline.
